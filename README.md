## OMIX-V11.4-DEBLOAT
* Omix cihazınızı debloat ederek cihazınızı tam performans'da kullanın.

### __`1 Adım:`__ Hata Ayıklama'yı aktif edin
* hata ayıklama'yı aktif ederek cihazınızı bilgisayarınıza micro usb kablosu yoluyla bağlayın.

### __`2 Adım:`__ Script Dosya'sını indirin
* dosya'yı indirdikten sonra yönetici olarak çalıştırın ve işlemin bitmesini bekleyin.

### __`3 Adım:`__ Cihaz Kontrolunuzu yapın
* eğer sistem uygulamaları halen cihazınızda gözüukuyor ise cihazınızı yeninden başlatın.

### Debloat Script'ini kurun:
* Script dosyasını [Buraya](https://github.com/j-chcode/OMIX-V11.4-DEBLOAT/releases/download/v11.4/omix_debloat.bat) tıklayarak indirebilirsiniz
